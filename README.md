# СМЕТА PRO

Telegram Mini App для строителей: ручные сметы, личные прайс-листы, строительные калькуляторы, учёт расходов и реальной прибыли по объектам, подписка через Telegram Stars.

## Что работает (этапы 1–3 + основа 5)

- Вход через Telegram: сервер проверяет подпись `initData`, создаёт аккаунт и 7 дней пробного периода.
- Справочник работ и материалов: несколько прайс-листов, история цен, копирование и перенос позиций. Цена копируется в смету при добавлении, поэтому изменения справочника не трогают сохранённые сметы. Обновить цены в смете можно вручную.
- Сметы: строки, категории, порядок, дублирование, копия сметы, шаблоны, автосохранение и восстановление несохранённого ввода, история изменений, поиск и фильтры.
- 20 калькуляторов (геометрия, бетон, кирпич, ГКЛ, отделка, древесина) с формулой, проверкой ввода и кнопкой «Добавить в смету» по ценам из справочника.
- Объекты: доходы, расходы по статьям, оплачено/не оплачено, план-факт, плановая, текущая и прогнозная прибыль, долг заказчика, контрольный список закрытия, журнал изменений.
- Подписка: тарифы в БД, оплата Telegram Stars, доступ продлевается только после `successful_payment`. Без подписки данные доступны для просмотра, изменения блокируются на сервере.
- Переключатель ИИ сохраняется на сервере и реально блокирует ИИ-запросы.

## Что требует подключения

| Что | Статус |
| --- | --- |
| Голосовой ИИ-сметчик (этап 4) | Интеграционный слой есть (`server/src/routes/ai.ts`), провайдер не выбран. Без `AI_PROVIDER` сервер честно отвечает «не подключён». |
| Цены тарифов | В таблице `Plan` стоят **тестовые** цены 1–20 ⭐. Поменяйте перед запуском. |
| Экспорт PDF/Excel (этап 6) | Не реализован. |
| Админ-панель | Не реализована; тарифы меняются в таблице `Plan` через Railway → Postgres → Data. |
| Возвраты Stars | Не реализованы. |

## Формулы

Все расчёты — в `shared/` (детерминированный модуль, без ИИ), деньги в копейках.

- Смета: подытог → резерв (% от материалов) → наценка → скидка → + доставка и доп. расходы → налог сверху. Себестоимость = Σ кол-во × закупочная цена.
- Объект: договор = база + доп. работы и изменения; долг = договор − получено; прибыль на сегодня = договор × % выполнения − начисленные расходы; прогноз = договор − (факт + остаток плана по статьям). Маржа считается только при выручке > 0.

Тесты: `npm test` (запускаются и при каждой сборке на Railway).

## Переменные окружения

| Переменная | Значение |
| --- | --- |
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
| `BOT_TOKEN` | токен от @BotFather |
| `SESSION_SECRET` | длинная случайная строка |
| `WEBHOOK_SECRET` | случайная строка (только буквы, цифры, `_`, `-`) |
| `PUBLIC_URL` | необязательно: адрес приложения, иначе берётся `RAILWAY_PUBLIC_DOMAIN` |
| `TRIAL_DAYS` | необязательно, по умолчанию 7 |
| `ADMIN_TG_IDS` | необязательно, Telegram ID администраторов через запятую |

## Локальная разработка

```
npm install
DATABASE_URL=... DEV_AUTH=1 SESSION_SECRET=dev npm run dev:server
npm run dev:web   # http://localhost:5173/?dev=1
```

`DEV_AUTH=1` разрешает вход без Telegram — никогда не включайте на проде.
