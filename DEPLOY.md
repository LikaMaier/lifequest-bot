# LifeQuest: мини-апп v2, деплой и проверка

## Что поменялось

- **Мини-апп стал полноценным приложением** (папка `static/`). Вкладки: Главная, Квесты, Карта недели, Прогресс, Награды, плюс Профиль и экран Premium.
- **Мини-апп работает через API бота.** Он больше не сохраняет данные через `sendData`: бот поднимает HTTP-сервер (`api.py`) в том же процессе. Сервер отдаёт и само приложение, и `/api/*`. Каждый запрос подписан Telegram (`initData`), сервер проверяет подпись по `BOT_TOKEN`.
- **Новые модули:**
  - `quests_database.py`: все задания (вынесены из бота);
  - `storage.py`: база и миграции;
  - `game.py`: XP, уровни, серия, ачивки, статистика;
  - `webapp_auth.py`: проверка подписи.
- **Бот:**
  - у бота появилась кнопка меню «Открыть LifeQuest», в `/start` добавлена кнопка приложения, `/board` открывает карту в приложении;
  - задания, выполненные в чате, тоже дают XP и попадают в статистику;
  - напоминания приходят по часовому поясу пользователя: он подставляется сам, когда пользователь впервые открывает приложение;
  - итог месяца снова отправляется. Раньше он не уходил никому из-за фильтра `profile IS NOT NULL`.
- **Старая база не теряется.** Таблицы и данные сохранены, новые колонки и таблицы добавляются автоматически при запуске. Прошлые выполненные и принятые задания переносятся в историю один раз.
- **Старая карта недели** (`index.html` в корне, GitHub Pages) остаётся запасным вариантом: кнопки клавиатуры, которые уже лежат в чатах пользователей, продолжают работать.
- **Groq убран:** он нигде не использовался.

## 1. Railway: тип сервиса и домен

1. В `Procfile` теперь `web: python lifequest_bot.py`: сервис слушает порт `$PORT`, Railway задаёт его сам.
2. Откройте сервис → **Settings → Networking → Generate Domain**. Получится адрес вида `https://lifequest-production.up.railway.app`.
3. Если в **Settings → Deploy → Custom Start Command** что-то указано, там должно быть `python lifequest_bot.py` (или очистите поле).

## 2. Volume для базы (обязательно)

Без Volume файловая система Railway обнуляется при каждом деплое, и вместе с ней пропадают XP, серии, ачивки и карты.

1. На схеме проекта щёлкните правой кнопкой по сервису → **Attach Volume** (или `Ctrl/⌘ + K` → «Volume»).
2. **Mount path:** `/data`.
3. Добавьте переменную `DB_PATH=/data/lifequest.db` (см. ниже).

Важно: сейчас база лежит внутри контейнера и уже обнулялась при прошлых деплоях. То, что накопилось с последнего деплоя, при этом деплое тоже пропадёт: Volume начнётся с пустой базы. Дальше данные сохраняются.

## 3. Переменные в Railway (Service → Variables)

| Переменная | Значение | Обязательно |
|---|---|---|
| `BOT_TOKEN` | токен от @BotFather (уже есть) | да |
| `ADMIN_ID` | ваш Telegram ID (уже есть) | для `/stats` |
| `DB_PATH` | `/data/lifequest.db` | да, вместе с Volume |
| `MINIAPP_URL` | `https://<ваш-домен>.up.railway.app/` (со слешем в конце) | желательно* |
| `GROQ_API_KEY` | можно удалить, больше не используется | нет |

\* Если `MINIAPP_URL` не задан или всё ещё указывает на `github.io`, бот сам возьмёт `RAILWAY_PUBLIC_DOMAIN`: Railway выставляет его автоматически после шага 1.2. Надёжнее задать `MINIAPP_URL` явно.

`PORT` задавать не нужно, Railway подставит его сам.

## 4. @BotFather (по желанию)

Кнопку меню «Открыть LifeQuest» бот ставит сам при запуске. Если хотите, чтобы приложение открывалось и из профиля бота:
`/mybots` → бот → **Bot Settings → Configure Mini App → Enable** → укажите тот же `MINIAPP_URL`.

## 5. Как проверить в Telegram

1. После деплоя откройте `https://<домен>/health` в браузере: ответ должен быть `{"ok": true}`.
2. В чате с ботом нажмите `/start`: сверху появится кнопка **«✨ Открыть LifeQuest»**, а слева от поля ввода — кнопка меню **«Открыть LifeQuest»**.
3. Откройте приложение и проверьте:
   - Главная показывает ваше имя, маскота, кольцо цели дня и три кнопки «Для себя / Для двоих / Для компании»;
   - нажмите «Для себя»: крутится рулетка, выпадает задание, нажмите «Принять вызов»;
   - на Главной в «Мои квесты» нажмите «Готово»: появятся «+XP», конфетти и ачивка «Первый шаг»;
   - вкладка «Карта»: впишите задачи, отметьте три клетки в ряд, засчитается «Линия собрана!». Закройте и снова откройте приложение: всё на месте;
   - вкладки «Прогресс» и «Награды» показывают выполненное;
   - Профиль (кнопка с буквой справа вверху): смените цель дня или цвет, нажмите «Поделиться достижением». Бот пришлёт картинку в чат.
4. В чате: `/myquests` → откройте задание → «Выполнено!». Во всплывающем уведомлении появится «+N XP», и в приложении это задание тоже будет засчитано.

Если приложение пишет «Не получилось загрузиться», посмотрите логи сервиса в Railway (Deployments → View logs).

## Локальный запуск и тесты

```bash
pip install -r requirements.txt
cp env.example .env     # и впишите BOT_TOKEN
python lifequest_bot.py # бот + сервер на http://localhost:8080
python -m unittest discover -s tests -t .
```

Открыть приложение в обычном браузере нельзя: оно работает только внутри Telegram, где есть подписанный `initData`. Для проверки в Telegram нужен HTTPS-адрес (Railway или туннель вроде `ngrok`).
